# CC2008 Programación Orientada a Objetos - Ejercicio 4

### Objetivo

Analizar las necesidades de una empresa y desarrollar una solución orientada a objetos en Java,
justificando la organización de las clases, sus responsabilidades y sus relaciones.

### Commands

Para compilar el programa se usa el siguiente comando: 
```bash
javac -d bin/ src/*.java
```

Para correr la aplicación en Windows:
```bash
java -cp bin/ Main
```

Para correr la aplicación en Linux/MacOS:
```bash
java -cp bin Main
```
